Hola

Soy Luis Alberto Pérez, desarrollador. Construí Cuentas Claras para resolver cálculos que en Venezuela se hacen todos los días a mano: convertir a la tasa del día, sacar el IVA y el IGTF de una factura, saber si el lunes hay banco o dividir una cuenta sin discusiones.

Desarrollo aplicaciones web y APIs con Angular, Django, Django Ninja y Next.js. Me gusta trabajar en proyectos que resuelven problemas concretos y convertir procesos complicados o manuales en herramientas simples y prácticas.

Cómo está montado

  • S3Bucket privado: no acepta tráfico público directo
  • CloudFrontCDN, HTTPS y Origin Access Control hacia S3
  • CloudFront FunctionsCómputo en el borde para resolver rutas de carpeta
  • ACMCertificado TLS gestionado
  • CloudFormationToda la infraestructura versionada como código

Sin servidores que administrar y sin EC2: el sitio se sirve desde un bucket privado a través de la CDN, y el cálculo ocurre en el navegador. Las tasas se consultan a APIs públicas de terceros, porque bcv.org.ve no permite consultas desde el navegador. El costo mensual es de centavos.

Stack de este sitio

HTML, CSS y JavaScript sin dependencias ni paso de compilación — el sitio entero pesa unos pocos KB y carga instantáneo. Infraestructura en CloudFormation. Todo el código está publicado.
